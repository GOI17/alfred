Connected agents

Connected means an authenticated request is open. Recently active means a request completed in the last 60 seconds; an idle client has no persistent connection. Open requests have a maximum 5-minute observation lease; after that, status is inactive until new activity.

Rows identify observed clients per credential and transport. Shared credentials may represent several agents. Activity is tenant-wide; workspace membership is unknown. This server process only, resets on restart, no replica aggregation; observations are bounded and retained for up to 24 hours.

4Coding agents (opencode / Codex / Pi)
Show steps 
1. cd into your project directory.
2. Run: alfred init --profile=coding --backend=sqlite --name=<project-name>
3. This writes .alfred/config.json in cwd with your API key.
4. The agent reads it on every session start.
5. Run the server: ALFRED_MEMORY_REQUIRE_AUTH=true alfred serve

What is this?

Alfred Memory is a multi-tenant memory store. The console manages which agents can talk to it and with which credentials.

Memory is never written here — it lives in each tenant's database (Postgres or SQLite). This page shows saved-memory history, observed client activity, and credentials.

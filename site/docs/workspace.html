Workspace

A local application for projects, conversations, files, terminals, and tools. Workspace runs independently of Memory and Agent Harness.

Availability. Workspace is integrated in source and requires a release after 1.1.0. Build the package from source or install a release whose runtime includes it. An installed 1.1.0 CLI does not gain Workspace from repository changes.

Start locally

alfred workspace serve --port 4310 --data-dir /absolute/path/to/workspace-state
# Equivalent standalone entrypoint:
alfred-workspace serve --port 4310 --data-dir /absolute/path/to/workspace-state

Open http://127.0.0.1:4310/. The default host is 127.0.0.1 and the default port is 4310. Keep state outside the installed package. --help and --version do not start services.

--host explicitly chooses an interface; --share opts into local-network listening. These Workspace options do not change Memory's loopback-only hosting policy.

Choose a session runtime explicitly

Workspace exposes SessionPort/SessionAdapter and accepts a supplied adapter through createApp({ sessionAdapter }). Runtime capabilities are reported by its descriptor endpoint. An injected runtime does not inherit legacy tools, permissions, credentials, or recovery.

The legacy adapter remains available for compatibility. No sibling Agent Harness runtime is discovered or configured automatically. This source migration does not add an Alfred Agent Harness SessionAdapter or promise ACP execution.

Local tools and optional browsers

The release includes the native terminal dependency for its target platform. Packaged terminal spawn/exit and web assets must pass validation on macOS/Linux, x64/arm64. Browser engines are separate, opt-in installations for browser tools; Homebrew installation does not download them. Workspace's other functions remain available without those engines.

Existing Workspace repository

The published source snapshot at 1e8c624d65e9814549d8604db181d716bc0dd0f4 is imported into packages/workspace, with file hashes and transformations recorded in upstream-snapshot.json. The original checkout and Git history remain preserved. This migration does not copy private state, credentials, or Memory tenant data.

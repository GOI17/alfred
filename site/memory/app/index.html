Alfred · Install

Your memory, running locally

Alfred Memory runs on your computer. The managed hosted service has been retired. This public page does not connect to your local API or collect an API key.

Start your local server

After installing Alfred, run these commands from your project directory:

alfred init --profile=coding --backend=sqlite --name my-memory
ALFRED_MEMORY_REQUIRE_AUTH=true alfred serve

Save the issued API key. Keep the server running, then open your local console and unlock it with that key.

If you choose a different local port, use the console URL printed by alfred serve --port 4321. The console and API share that origin.

Storage and clients

The coding profile supports a local SQLite database. Existing authentication, tenants, MCP clients and user-chosen Postgres storage remain supported. A remote Postgres database does not expose the local HTTP server.

Clients must be able to reach this computer's loopback address. Cloud ChatGPT Actions and AI Studio cannot call this local-only API.

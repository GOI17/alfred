Alfred support

Official product support from AlfredLabs.

Email alfred.support@alfredlabs.org for Alfred and Alfred Memory account, connection, privacy, or deletion help.

What to include

  • The product and client you are using, such as the local Alfred Memory console or a coding client.
  • A short description of the problem and the time it occurred.
  • Any non-sensitive error message or request identifier.

Never send passwords, API keys, OAuth tokens, private keys, or memory contents by email.

Security reports

Use the support address for suspected security or privacy issues and put Security in the subject. Do not publish account-specific details in a public issue.

Open-source project

Public bug reports and feature requests that contain no private data may also be filed in the Alfred issue tracker.

Publisher
